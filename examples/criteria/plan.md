# Search feedback

Explain empty search results and give people a useful next action. Milestone 1 delivers AC-01.

## Acceptance criteria

- AC-01: Empty search results explain why nothing matched.
- AC-02: The empty state offers one next action,
  such as clearing the active filters.
- AC-03: The explanation and the action work with a keyboard and a screen reader.

## Notes for reviewers
