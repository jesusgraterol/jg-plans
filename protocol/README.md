# The jg-plans protocol

A plan is an ordinary Markdown document. Optional metadata makes it easier to identify and revise; optional milestones describe progress when a task benefits from separate review boundaries.

| Version | Status            | Specification                 |
| ------- | ----------------- | ----------------------------- |
| 0.1     | Provisional draft | [Protocol 0.1](0.1/README.md) |

The protocol belongs to jg-plans. Applications choose their own approval, execution, coordination, and retention policies. The reference library and CLI are implementations of this protocol, not prerequisites for using it.

Start with the [small plan](../examples/small/plan.md), compare [optional milestones](../examples/with-milestones/milestones.md), or explore [the examples](../examples/README.md).

Protocol versions are independent of npm package versions. Version 0.1 remains provisional until jg-skills and at least one HQ consumer exercise separately approved integrations. Their adoption is not required to finish this project's first implementation.
